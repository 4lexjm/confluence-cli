# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within `confluence-cli`, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report security issues by emailing security@atlassian.com or opening a private advisory on GitHub.

When reporting, please provide:
- A description of the vulnerability
- Steps to reproduce or proof of concept
- Potential impact
- Any suggested fix or remediation

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to resolve the issue promptly.
